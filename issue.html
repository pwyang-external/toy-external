🎫 사내 상품권 발급 도구

코드 생성 자체는 인터넷 없이 동작합니다. GitHub에 발급 기록을 남기려면 비밀키만 맞게 입력하면 되고, 그 경우만 인터넷이 필요합니다.

비밀키(SECRET KEY)는 발급자와 검증자만 알아야 하는 값입니다.
이 값을 잊으면 검증 자체가 불가능하고, 유출되면 누구나 위조 가능합니다. 안전한 곳(예: 비밀번호 관리자)에 별도 기록해두세요.

💡 이 비밀키는 make-config.html에서 GitHub 설정을 암호화할 때 쓴 암호와 같아야 합니다. GitHub owner/repo/token은 여기서 따로 입력하지 않고, 전부 make-config.html에서 만든 설정 파일에서 자동으로 가져옵니다.
